# Help-center search and SEO

Open public search with the **Search…** control, or press **⌘K** on Mac, **Ctrl+K** on other systems, or `/` when you are not typing in a field. Search finds published help articles by title, description, and body text. It ranks matching articles and shows a short excerpt. This search is separate from Maven's AI Search over knowledge sources.

## Set article search details

In an article's **Publish settings**, review its title, URL slug, description, and Open Graph image. The title and description are used in page metadata. If you leave the description blank, ReplyMaven can fill it from the first text line in the article body. If you leave the Open Graph image blank, it can use the first image in the body. The editor shows warnings for missing or unsuitable SEO fields.

The published page includes a canonical URL, Open Graph metadata, Article and Breadcrumb structured data, and a sitemap entry. Review the slug before you publish. Changing a published slug changes the URL, so update links that use the old one.

When you use a custom help-center domain, ReplyMaven treats its hosted `/help/<project>` pages as non-canonical and noindex. The custom-domain guide explains the proxy setup: [Host help on your own domain](https://replymaven.com/docs/knowledge-base/host-help-on-your-own-domain).

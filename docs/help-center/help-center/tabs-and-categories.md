# Organize tabs and categories

Open your project and choose **Help Center → Articles**. Use tabs to group categories into sections such as Docs, Changelog, or API. Use categories to group related articles inside each tab.

## Add and order tabs

When no tabs exist, choose **Add tabs**. After you create tabs, choose **Manage tabs** to add, rename, or reorder them. A help center supports up to six tabs. The first tab owns the public home page and adopts categories that are not assigned to a tab. Each category belongs to one tab.

A tab must be empty before you can delete it. Move its categories to another tab or archive them first. The public help center shows its tab bar only when at least two tabs have published articles. Tab changes do not add the tab name to category or article URLs.

## Add and manage categories

Choose **New Category**. Set its name and, if needed, choose a tab. You can also set a URL slug, description, and icon. If you leave the slug blank, ReplyMaven makes one from the category name. Drag categories to change their order.

To change a category, open its edit action in the category list. A new slug changes the category URL, so update links that point to the old one. To remove a category from the public help center, archive it. This hides the category and unpublishes its published articles. The article records remain in ReplyMaven.

Use **New Article** after you select a category. See [Write and publish an article](https://replymaven.com/docs/help-center/write-and-publish-articles).

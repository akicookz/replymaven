# Edit the help-center home page

Open **Help Center → Home page**. Type `/` in the editor to add a **Search**, **Categories**, or **Popular articles** block. You can add and arrange text and images around these blocks.

Use the background control to add or adjust the page background image. Choose **Save** to store your changes. Choose **View live** to open the current help-center page.

The public home page belongs to the first tab. If the help center has tabs, categories are listed under the tab they belong to. The public tab bar appears only when at least two tabs have published articles. See [Organize tabs and categories](https://replymaven.com/docs/help-center/tabs-and-categories).

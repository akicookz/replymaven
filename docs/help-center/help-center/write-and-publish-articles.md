# Write and publish an article

Open **Help Center → Articles**, select a category, and choose **New Article**. You can also create a category with **New Category** if you need one first.

## Write the article

Enter a title and choose a category in **Publish settings**. ReplyMaven derives a URL slug from the title when you leave the slug blank. You can add a description and an Open Graph image for link previews and search metadata.

Write the body in the editor. Type `/` to insert headings, lists, checklists, quotes, callouts, code blocks, tables, images, links, steps, and API blocks. Use **Preview** to see the page before it goes live.

Choose **Create** or **Save** to store the article as a draft or save your edits. New articles start as drafts. To publish a new article, save it first, then choose **Publish**. To take it off the public site, choose **Unpublish**. Save edits to a published article to update the live page.

Published help articles are also sent for AI Search indexing. Indexing runs in the background. Check the article list for its indexing status.

See [Organize tabs and categories](https://replymaven.com/docs/help-center/tabs-and-categories) and [Help articles feed your AI](https://replymaven.com/docs/knowledge-base/help-articles-as-knowledge).

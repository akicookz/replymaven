# Set the help-center theme, navigation, and analytics

Open **Help Center → Articles** and choose **Site settings**.

## Theme and style

Choose the default theme: **System**, **Light**, or **Dark**. You can also add custom CSS for the help center. Save your changes to apply them.

## Top navigation

Add up to three links to the top navigation. Each link needs a label and an HTTPS URL. The URL must point outside `replymaven.com`. Use this for links such as your main website or account page.

## Analytics

The Analytics settings support PostHog, Google Analytics, Meta Pixel, and a custom script URL. A custom script URL runs only when the help center uses a custom domain. Add only the analytics entries you use, then save.

To serve help pages from your domain, follow [Host help on your own domain](https://replymaven.com/docs/knowledge-base/host-help-on-your-own-domain).

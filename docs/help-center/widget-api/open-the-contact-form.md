# Open the contact form

Open the configured contact form with the widget API:

```javascript
window.ReplyMaven?.open("form");
```

If the widget is closed, this opens it on the form screen. The form must be enabled in **Settings → Quick actions**. If no form is configured, the widget returns to its home screen.

You can also add a quick action that opens the form. See [Contact form](https://replymaven.com/docs/integrations/contact-form) for setup details.

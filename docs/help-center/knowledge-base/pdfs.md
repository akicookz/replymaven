# Upload PDFs

Upload PDFs as knowledge sources on **Maven → Knowledge → Sources**. The file limit is 10 MB per PDF. PDF indexing depends on your plan's PDF entitlement. If your plan does not include PDFs, ReplyMaven blocks the upload.

PDFs can hold manuals, setup guides, policies, and other reference material. After upload, ReplyMaven extracts the content and queues it for AI Search indexing. Check the resource status on the Sources page if indexing has not completed.

Use PDFs with selectable text. Check the extracted content before relying on a scanned document.

# Add web pages

Add a URL on **Maven → Knowledge → Sources**. ReplyMaven fetches and extracts the page, then queues the content for AI Search indexing.

When a page is added, ReplyMaven can discover linked pages on the same origin. The crawl follows links one level from the starting page and can discover up to 50 pages for the resource. It does not crawl every page on a large site.

Open the resource to review and edit crawled page content. Re-crawl a page when its source has changed. Check the Sources page for crawl and indexing status.

Start with pages that answer common customer questions, such as pricing, setup, troubleshooting, and policies. More relevant pages make it easier to find useful source content.

See [How RAG works](https://replymaven.com/docs/knowledge-base/how-rag-works) to learn how indexed pages are used in answers.

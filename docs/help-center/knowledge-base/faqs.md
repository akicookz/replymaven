# Create FAQs

Create question-and-answer resources on **Maven → Knowledge → Sources**. FAQs give Maven short answers to specific customer questions.

To write an FAQ:

- Use the words a customer is likely to use.
- Keep each pair focused on one question.
- Include exact facts, limits, steps, and links in the answer.

You can also select **Generate FAQ** on the Sources page. Enter a topic and choose webpage or PDF sources. If you select no sources, the generator uses all eligible webpage and PDF resources. It combines the selected source text with company context and returns draft pairs for you to review and save. It does not draft from closed conversations.

See [How RAG works](https://replymaven.com/docs/knowledge-base/how-rag-works) to learn how Maven uses FAQ resources.

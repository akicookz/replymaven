# Set Maven's tone of voice

Set Maven's tone under **Maven → Behavior → Persona**. Choose a preset or write a short custom tone prompt.

| Tone | Style |
| --- | --- |
| Professional | Clear and business-appropriate. |
| Friendly | Warm and conversational. |
| Casual | Relaxed and informal. |
| Formal | Structured and authoritative. |
| Custom | Describe how Maven should communicate. The prompt can contain up to 2,000 characters. |

The tone guides Maven's customer-facing replies. It works with your company knowledge, assistant name, and human agent label. A custom tone prompt changes the style and behavior of replies. It does not replace the full system prompt.

For example: `When a visitor is frustrated, acknowledge it in one sentence before answering.`

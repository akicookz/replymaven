# Colors, fonts, and border radius

Set these options in **Settings → Appearance**. They apply to the widget for this project.

| Setting | Description |
| --- | --- |
| Brand Color | Used for the trigger button, header tint, send button, visitor bubbles, and accent elements. Hex format (for example `#2563eb`). The chat window uses a frosted glass style with this color as a tint. |
| Brand Text | Text color on branded elements (buttons, icons, header). Hex format (for example `#ffffff`). |
| Font Family | Custom font for the widget. Falls back to the system font stack. |
| Border Radius | Roundness of the chat window corners (0-50px). |

> [!TIP]
> Pick a brand color with enough contrast against white text, or adjust Brand Text to keep buttons readable.

For deeper changes, see [Custom CSS](https://replymaven.com/docs/customization/custom-css).

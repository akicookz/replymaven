# Header and avatar

Configure the chat window header text and bot avatar under **Settings → Appearance**.

The avatar appears in:

- The floating trigger button (it replaces the default chat icon)
- The chat header
- The home screen
- Next to each bot and agent message
- The browser notification icon

> [!TIP]
> Upload a square image of at least 128x128px for the best results. PNG or WebP with a transparent background works well.

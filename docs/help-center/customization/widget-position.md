# Widget position

Set the widget position under **Settings → Appearance**.

- **Bottom Right** (default): the standard position for most websites.
- **Bottom Left**: useful when other elements already occupy the bottom-right corner, such as a cookie banner or another floating button.
- **Center Inline**: show a message input bar centered at the bottom of the screen instead of the corner launcher.

The bottom-corner positions apply to the launcher and opened chat window. Center Inline opens chat from its bottom-centered input bar.
